Instalación y Configuración de ChunkLab
1. Preparación del Entorno

Para garantizar la reproducibilidad de los experimentos y evitar conflictos entre dependencias, se recomienda utilizar un entorno virtual de Python. Una vez creado y activado el entorno, se deben instalar las dependencias requeridas por el proyecto y registrar el paquete ChunkLab en el entorno de ejecución.

Instalación de dependencias

Ejecute el siguiente comando para instalar todas las bibliotecas necesarias:

.venv\Scripts\python -m pip install -r requirements.txt


Este comando:

Utiliza el intérprete de Python asociado al entorno virtual .venv.
Lee el archivo requirements.txt.
Descarga e instala automáticamente todas las dependencias requeridas por el proyecto.
Garantiza que se utilicen las versiones especificadas por los desarrolladores.

Un archivo requirements.txt puede incluir dependencias como:

langchain
chromadb
sentence-transformers
pyyaml


Durante la ejecución, pip descargará e instalará automáticamente cada uno de los paquetes definidos.

2. Instalación de ChunkLab

Una vez instaladas las dependencias, se debe registrar el proyecto en el entorno local mediante una instalación editable:

.venv\Scripts\python -m pip install -e .


La opción -e (editable) indica que el proyecto será instalado directamente desde el directorio actual.

Ventajas de la instalación editable
Registra el paquete dentro del entorno virtual.
Permite ejecutar los módulos del proyecto desde cualquier ubicación del entorno.
Los cambios realizados en el código fuente se reflejan inmediatamente.
No es necesario reinstalar el paquete después de cada modificación.

Este mecanismo resulta especialmente útil durante las etapas de desarrollo, prueba y validación experimental.

¿Qué es ChunkLab?

ChunkLab es una herramienta de evaluación y experimentación orientada al análisis de estrategias de fragmentación documental (chunking) en sistemas de Recuperación Aumentada por Generación (RAG - Retrieval-Augmented Generation). Su finalidad es comparar distintos métodos de segmentación de documentos y analizar el impacto que cada estrategia produce sobre el rendimiento de los procesos de recuperación de información.

La plataforma facilita la evaluación objetiva de diferentes enfoques de fragmentación, tales como:

Fragmentación de tamaño fijo (Fixed Chunking).
Fragmentación recursiva (Recursive Chunking).
Segmentación basada en oraciones (Sentence-based Chunking).
Fragmentación semántica (Semantic Chunking).
Estrategias jerárquicas (Parent Document Chunking).

Asimismo, permite medir indicadores de desempeño ampliamente utilizados en recuperación de información, entre ellos:

Recall@k
Mean Reciprocal Rank (MRR)
Normalized Discounted Cumulative Gain (nDCG)
Ejecución de una Prueba de Concepto (PoC)

Una vez instalado el paquete, es posible ejecutar una prueba de concepto mediante el siguiente comando:

python -m chunklab.poc run --config config/poc_smoke.yaml

Descripción del comando

Este comando ejecuta una Proof of Concept (PoC) definida mediante un archivo de configuración en formato YAML.

El archivo config/poc_smoke.yaml contiene los parámetros necesarios para la ejecución del experimento, incluyendo:

Corpus documental a analizar.
Estrategia de fragmentación.
Método de recuperación.
Configuración de indexación.
Métricas de evaluación.
Parámetros generales del experimento.

La ejecución de esta prueba permite validar el correcto funcionamiento del pipeline completo antes de realizar experimentos de mayor escala o evaluaciones comparativas.
